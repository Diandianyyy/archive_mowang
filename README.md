# Mowang source archive

Upstream: https://mowang7426.github.io/mowang/

Public APT source: https://diandianyyy.github.io/archive_mowang/

Add the public URL to Cydia, Sileo, or Zebra. GitHub Actions checks the upstream source every six hours, verifies package SHA-256, size, and DEB format, and preserves previously archived versions. Each run downloads at most 100 new packages by default; a manual run with `max_downloads=0` completes all missing packages in batches.
